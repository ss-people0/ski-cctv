# 스키장 CCTV

X6+ 시즌패스(26/27) 스키장 6곳의 웹캠을 한 화면에서 보는 개인용 페이지입니다.

## 실행

```sh
npm install
npm run dev                             # PC에서 보기
npm run dev -- --host --port 5199       # 같은 와이파이의 휴대폰에서 보기 (http://<Mac IP>:5199)
npm test
npm run build
```

## 스키장별 방식

| 스키장 | 카드 | 방식 |
|---|---|---|
| 웰리힐리파크 | 6 | HLS 5개, 정상광장은 링크 |
| 하이원리조트 | 18 | HLS (앱을 `http`로 열 때만 재생) |
| 모나용평 | 7 | HLS |
| 알펜시아 | 1 | 유튜브 라이브 |
| 엘리시안강촌 | 1 | 링크 |
| 지산리조트 | 5 | 오픈 준비 중 |

## 기능

- 눌러야 재생되고, 한 번에 하나만 재생합니다.
- HLS는 15초(하이원 30초) 뒤 자동으로 꺼집니다.
- 크게 보기: PC는 팝업, 모바일은 큰 화면입니다.
- 재생되는 곳이 위, 오픈 전인 곳이 맨 아래에 나옵니다.

## 웹캠 주소 바꾸기

`src/data/cams.ts`만 고치면 됩니다. 바로 재생하려면 `status: 'active'`와 재생용 `type`(`hls` 또는 `youtube`), 주소(`url` 또는 `videoId`)가 모두 필요합니다.

## 주의

개인용입니다. 공개 배포 전에는 리조트별 임베드 약관을 확인해야 합니다. `https`로 배포하면 하이원은 재생되지 않습니다.
